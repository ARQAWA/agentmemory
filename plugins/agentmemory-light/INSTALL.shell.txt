AgentMemory Light: установка

1. Установите весь каталог AgentMemory Light через штатный механизм плагинов
Codex. Сохраните версию `0.0.0`.

2. Скопируйте поставляемый `scripts/mcp-proxy.cjs` в постоянное место
пользователя без изменений. Для запуска нужен Node.js 20 или новее.

3. Подключите глобальный MCP `agentmemory` через этот адаптер к
`http://agentmemory.chat.openai.com/mcp`. Укажите в `HTTP_PROXY` существующий
локальный HTTP proxy из защищённой MCP-настройки, без логина и пароля. Если
адрес неизвестен, запросите его и не угадывайте.

4. Включите четыре hooks плагина обычным механизмом доверия Codex.

5. Перезапустите Codex или создайте новую задачу, чтобы установка загрузилась.

Сохраните остальные плагины и настройки. Отдельный профиль агента и видимые
skills не нужны.
