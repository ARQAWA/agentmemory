AgentMemory Light: установка для Codex

1. Используйте полный каталог agentmemory-light, включая скрытый
.codex-plugin, scripts/vendor, references и hooks. В пакете есть автономный
JavaScript-файл .cjs и исходные данные. Сборка репозитория и npm не нужны.
Сохраните другие настройки, плагины и профили. Этот пакет не добавляет профиль
агента, AGENTS.md и зарегистрированные skills.

2. Найдите текущую конфигурацию пользователя через уже заданный CODEX_HOME
или каталог .codex домашнего каталога. Сохраните активный пользовательский
каталог и используйте штатный native marketplace flow. Скопируйте полный
каталог в стабильный каталог исходников пользовательского плагина. Затем
зарегистрируйте и установите пакет через подтверждённый marketplace и штатный
plugin-creator/native flow. Не угадывайте имя marketplace и не удаляйте его
записи. Версия должна оставаться 0.0.0, без cachebuster.

3. Скопируйте scripts/mcp-proxy.cjs в стабильный пользовательский каталог
адаптера вне временного cache. Копия должна быть байт-в-байт такой же. Не
редактируйте JavaScript. Адаптер получает URL сервера первым аргументом и
использует HTTP_PROXY из окружения MCP. Второй адаптер или отдельный сетевой
клиент не нужен.

4. Измените только canonical mcp_servers.agentmemory. Укажите фактический
абсолютный путь к native Node.js версии 20 или новее, без .cmd, .bat и shell
алиаса. В args укажите фактический абсолютный native путь к скопированному
.cjs и URL `http://agentmemory.chat.openai.com/mcp`. Сохраните
startup_timeout_sec=30 и tool_timeout_sec=180. В env задайте фактический
локальный HTTP endpoint для HTTP_PROXY и пустой NO_PROXY. Этот endpoint
должен быть существующим локальным HTTP forward proxy без логина и пароля;
он уже выполняет защищённую маршрутизацию. Не угадывайте порт, не копируйте
учётные данные и не используйте общий proxy для интернета. Если endpoint не
найден в существующей конфигурации, остановитесь и запросите его.

5. Для записи TOML определите реальные абсолютные пути на целевой системе.
Используйте штатный инструмент преобразования путей среды, включая Windows
формат и прямые слеши, если он уже предусмотрен. Не применяйте строковые
эвристики, не вставляйте пользовательские или macOS пути, кавычки в args,
`~` или `$VAR`. Native Node запускается через execFile без shell; тот же
command и args используются для HTTP-вызовов hooks.

6. После установки проверьте пакет версии 0.0.0, совпадение скопированных
файлов, четыре точных trusted hooks через штатный Codex app-server и отсутствие
видимых Light skills. Не обходите approval или trust. Создайте новую задачу
или перезапустите host, чтобы загрузилась текущая установка. Отдельный
профиль агента и регистрация skills не требуются.

7. Установка считается завершённой только при наличии пакета, профиля hook
trust и одной canonical записи adapter. Эта подготовка не доказывает работу
Windows runtime. При одинаковом basename проекта сохраняется один memory
scope; существующие идентификаторы не меняйте.
